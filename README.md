# Eliazel Hitwamata — Portfolio

Responsive dark React portfolio built with Vite, configured for GitHub Pages at `https://hitwamata.github.io/portifolio-eliazel/`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Personal details live in `src/config.js`. Add your real LinkedIn URL when ready. The project examples should be reviewed for accuracy before public sharing; demo concepts are not presented as shipped client work. Add your CV at `public/Eliazel-Hitwamata-CV.pdf` if you want the CV link to work.
